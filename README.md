# Mengistu Birhan - Professional Portfolio

Welcome to my personal professional portfolio web application! This project showcases my skills, experience, and projects as a Software Engineer.

## 🚀 Live Demo
- Cloud Hosting: [coeco.vercel.app](https://coeco.vercel.app) *(or your deployed portfolio link)*

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend & Services:** Node.js, Supabase
- **Version Control & Hosting:** GitHub, Vercel

## ✨ Key Features
- **Modern Hero Section:** Clean introduction featuring name, role, and core expertise without redundant phrasing.
- **Skills Showcase:** Organized bullet points and cards highlighting full-stack development proficiencies (React, TypeScript, Node.js, Databases).
- **Responsive Navigation:** Interactive Navbar with smooth hover effects, fully optimized for mobile, tablet, and desktop viewports.
- **Direct Contacts & Socials:** Integrated clickable links for GitHub, LinkedIn, Telegram, WhatsApp, and direct phone contact.
- **Professional Resume Access:** Quick "View Resume" action opening directly in a new browser tab.
